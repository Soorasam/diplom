## Коопзакупки — Якутия

**Коопзакупки — Якутия** — цифровая платформа для кооперативных закупок и доставки товаров в труднодоступные населённые пункты Республики Саха (Якутия). Продукт объединяет участников закупа, водителя и жителей посёлков на маршруте в одном сервисе.

### Ключевые возможности

- **Каталог и корзина**: выбор товаров, оформление заказа, отслеживание статусов.
- **Сборы (кооперативные закупки)**: совместное формирование заказов по маршрутам доставки.
- **Логистика**: маршрут с точками закупа и выдачи в посёлках, фиксация прогресса рейса.
- **Закупка и чеки**: чек-лист закупки, фото чеков, сверка суммы.
- **Споры/поддержка**: обращения по заказам, чат, вложения (фото/документы), статусы обработки.

### Роли пользователей

- **Житель (клиент)**: выбирает товары, участвует в сборе, оплачивает и подтверждает получение у водителя.
- **Водитель/координатор**: открывает сбор, закупает по маршруту, везёт и вручает заказы, закрывает этапы рейса.
- **Администратор**: управляет каталогом, пользователями, населёнными пунктами и обработкой обращений.

### Технологии

- **Frontend**: React + TypeScript + Vite, React Router, TanStack Query, Tailwind CSS, PWA.
- **Backend**: NestJS + TypeScript, Prisma.
- **Данные и хранение**: PostgreSQL, MinIO (S3‑совместимое хранилище медиа).
- **Инфраструктура**: Docker, Nginx.
