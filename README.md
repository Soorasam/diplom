## Коопзакупки — Якутия

**Коопзакупки — Якутия** — цифровая платформа для кооперативных закупок и доставки товаров в труднодоступные населённые пункты Республики Саха (Якутия). Продукт объединяет участников закупа, логистику и пункт выдачи в одном сервисе.

### Ключевые возможности

- **Каталог и корзина**: выбор товаров, оформление заказа, отслеживание статусов.
- **Сборы (кооперативные закупки)**: совместное формирование заказов по маршрутам доставки.
- **Логистика**: маршрут с точками закупа и точками выдачи, фиксация прогресса доставки.
- **ПВЗ (пункт выдачи заказов)**: приёмка и выдача заказов с чек‑листами операций.
- **Споры/поддержка**: обращения по заказам, чат, вложения (фото/документы), статусы обработки.
- **Офлайн‑устойчивость**: локальная очередь действий на случай нестабильного интернета для части операций ПВЗ.

### Роли пользователей

- **Житель (клиент)**: выбирает товары, участвует в сборе, оформляет и получает заказ.
- **Водитель/координатор**: выполняет закуп и доставку по маршруту, отмечает этапы.
- **Сотрудник ПВЗ**: принимает поставки, выдаёт заказы, работает по чек‑листам.
- **Администратор**: управляет каталогом, пользователями, маршрутами и обработкой обращений.

### Технологии

- **Frontend**: React + TypeScript + Vite, React Router, TanStack Query, Tailwind CSS, PWA.
- **Backend**: NestJS + TypeScript, Prisma.
- **Данные и хранение**: PostgreSQL, MinIO (S3‑совместимое хранилище медиа).
- **Инфраструктура**: Docker, Nginx.
